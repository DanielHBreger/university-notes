# `chua/s3014a.py` and `chua/config.ini`

The program that was running on the bench PC to capture the records. It is not part of the analysis and nothing imports it; it is kept so the acquisition settings are on record. It needs `pyvisa`, numpy, matplotlib and tkinter, and talks to the Agilent/Keysight DSO-X 3014A over USB.

## Settings (top of the file, overridable from `config.ini`)

- `RAW_POINTS = 1000000`: one million points per channel per capture, the scope's deep memory. This is why each `traceN.csv` holds 10⁶ rows.
- `TIMEBASE_CHOICES`: the s/div values offered in the toolbar. The sweeps were taken at two settings, which is why the sample interval changes from 400 ns to 1 µs partway through `forward/`.
- `MIN_PERIODS_WARN = 50`: warns if a record holds fewer than fifty cycles.
- `CHANNELS = (1, 2, 3, 4)`: only the displayed channels are read; the sweeps used three.

## `find_scope()`

Lists VISA resources and picks the one whose identification string names the instrument.

## `class Oscilloscope`

The instrument wrapper. `active_channels`, `input_impedances`, `get_screen_settings` query the scope; `set_timebase` and `measure_frequency` set and read it; `_acquire` performs a single deep-memory capture (the transfer timeout scales with the point count); `get_trace(channels, deep=True)` returns time and voltage arrays and restores the sweep mode and timebase afterwards.

## `envelope_decimate(t, y, max_points)`

Reduces a million points to `MAX_DISPLAY_POINTS` for drawing by keeping the minimum and maximum of each block, so clipping and spikes remain visible on screen. The saved CSV is never decimated.

## `class App`

The Tk window: connect and reconnect, choose channels and timebase, capture, toggle between the Y–t view and the XY (phase-portrait) view, and save. `save()` writes the CSV with the header `Time(s),CH1(V),CH2(V),...` in `%.6e` format, which is the format `scope_data.read_scope` expects and the reason for the timestamp tolerance discussed in [scope_data.md](scope_data.md). `remember_save_path` keeps the last folder in `config.ini`.
